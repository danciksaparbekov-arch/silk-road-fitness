## Решение 18.11: проверка тренировки без Strava (бесплатно) — ждёт скриншот
План согласован с пользователем, код ещё не писался:
- Кнопка «Проверить» после тренировки → выбор **скриншота итогов тренировки из Mi Fitness**.
- OCR в браузере (Tesseract.js, грузить лениво только по кнопке, офлайн) читает длительность, средний пульс, время старта, тип → заполняет форму; пользователь подтверждает/правит. Если OCR не справился — **ручной ввод** тех же полей.
- Скриншот + проверки пройдены = «подтверждено»: бонус ×1.2 без штрафа (готовый флаг «Проверка часами» в game.js/index.html). Только ручной ввод = «не подтверждено»: без бонуса, без штрафа.
- Проверки: длительность ≥25 мин, пульс правдоподобен, время внутри игрового дня и совпадает с сессией, повторный скриншот отклоняется (храним хэш, не картинку). Картинка не покидает телефон.
- Оценка ~60–80k токенов (код — Sonnet-агентом, дизайн и ревью — я), бот не меняется, перевыкатка не нужна.
- **Блокер:** один реальный скриншот сводки тренировки Mi Fitness (подойдёт любая прошлая из истории, даже прогулка; иначе короткая тренировка в режиме тренировки на часах). Положить в папку репо или прислать в чат.
- Позже (пользователю понравилось): нативный Android-мост через Health Connect (Mi Fitness → Профиль → данные сторонних приложений → Health Connect). PWA его не читает, нужен свой APK; дорого.
- Отложено: камерный счётчик повторов (MediaPipe) — круто, но самый дорогой; акселерометр телефона — вариант на потом.
- Идея без решения: упражнения-удержания (dead hang, L-sit, негативы) как отдельный тип юнита, например «крепость» → защита.
