# Бот напоминаний «Шёлковый путь»

Telegram-бот на Cloudflare Worker. Приложение отправляет боту минимальный статус (расписание и «выполнена ли норма сегодня»), а бот по расписанию (cron раз в 10 минут, часовой пояс Бишкек UTC+6) шлёт напоминания голосом врага. Игровое состояние живёт только в приложении.

Что нужно: аккаунт Telegram, бесплатный аккаунт Cloudflare, установленный Node.js. Все команды ниже для PowerShell, выполнять в папке `bot`.

> Токен бота никогда не вставляй в файлы репозитория и не пересылай в чат. Он вводится только в ответ на запрос `wrangler secret put`.

## 1. Создать бота в Telegram
1. В Telegram открой `@BotFather`, отправь `/newbot`.
2. Задай имя (любое) и username, оканчивающийся на `bot`, например `silk_road_fit_bot`.
3. BotFather пришлёт токен вида `123456:ABC...`. Сохрани его в менеджере паролей. Больше он нигде не нужен, кроме шага 4.
4. Запомни username: он понадобится для `BOT_USERNAME` в `sync.js`.

## 2. Войти в Cloudflare
```powershell
cd "C:\Users\user\Личное\silk-road-fitness\bot"
npx wrangler login
```
Откроется браузер, нажми «Allow».

## 3. Создать хранилище (KV)
```powershell
npx wrangler kv namespace create STATE
```
Команда напечатает блок с `id = "..."`. Скопируй этот id в `wrangler.toml`, заменив `REPLACE_WITH_KV_ID`.

## 4. Задать секреты
```powershell
npx wrangler secret put TELEGRAM_BOT_TOKEN
npx wrangler secret put WEBHOOK_SECRET
```
- На первый запрос вставь токен от BotFather.
- На второй придумай длинную случайную строку из латинских букв и цифр (32+ символов). Её можно сгенерировать так: `-join ((48..57)+(97..122) | Get-Random -Count 40 | % {[char]$_})`. Запомни её для шага 6.

Секреты создаются вместе с Worker. Если wrangler спросит про создание нового Worker, согласись (`y`).

## 5. Задеплоить
```powershell
npx wrangler deploy
```
В конце будет адрес вида `https://silk-road-bot.<твой-аккаунт>.workers.dev`. Это `WORKER_URL`.

## 6. Подключить вебхук Telegram
Токен и секрет подставляются из переменных текущей сессии PowerShell, в файлы они не попадают:
```powershell
$token = Read-Host "Токен бота"
$secret = Read-Host "WEBHOOK_SECRET (тот же, что в шаге 4)"
$url = "https://silk-road-bot.<твой-аккаунт>.workers.dev/webhook"
Invoke-RestMethod -Method Post -Uri "https://api.telegram.org/bot$token/setWebhook" -ContentType "application/json" -Body (@{ url = $url; secret_token = $secret } | ConvertTo-Json)
Remove-Variable token, secret
```
Ответ должен содержать `ok : True`. Telegram будет добавлять к каждому запросу заголовок `X-Telegram-Bot-Api-Secret-Token`, Worker отвергает запросы без него (401).

## 7. Прописать адреса в приложении
В файле `sync.js` (корень репозитория) заполни две константы вверху:
```js
var WORKER_URL='https://silk-road-bot.<твой-аккаунт>.workers.dev';
var BOT_USERNAME='silk_road_fit_bot';
```
Если у приложения другой адрес (не GitHub Pages `danciksaparbekov-arch.github.io`), поправь `ALLOWED_ORIGINS` и `GAME_URL` в `wrangler.toml` и снова выполни `npx wrangler deploy`. Закоммить и запушь изменения, чтобы обновилась страница.

## 8. Подключить свой чат
В игре: Настройки, блок «Напоминания», кнопка «Подключить Telegram». Откроется бот, нажми «Запустить». Бот ответит, что связь установлена.

Команды бота: `/status` (норма на сегодня), `/stop` (отключить напоминания).

## Расписание
Тихие часы 23:30–07:30. Каждый вид сообщения приходит не чаще раза за игровой день и только если норма не выполнена:
- 08:00 утреннее (тренировка A/B, время, гарнизон; в день отдыха напоминание про мобильность и еду);
- 20:50 «курсы закончились?» (только в дни тренировок);
- 22:30 последнее предупреждение о ночном набеге;
- воскресенье 19:00 итоги недели (приходят и при выполненной норме).

Перемирие отключает всё. Данные приложение отправляет при каждом сохранении и при открытии. Если сегодня игру не открывали (синхронизация от прошлого дня, не старше 2 суток), бот сам определяет день тренировки по расписанию и считает норму невыполненной: напоминания приходят. Если синхронизации нет больше 2 суток, раз в 3 дня придёт мягкое «давно не заходил». Кнопка «⏰ +30 мин» повторяет сообщение позже.

## Безопасность
- Токен хранится только как секрет Cloudflare (`TELEGRAM_BOT_TOKEN`), вебхук проверяется секретом `WEBHOOK_SECRET`.
- Код привязки (16 случайных символов) хранится в приложении и в KV, это ключ доступа. Он не пишется в логи. Если код утёк, очисти данные браузера или сбрось его, и подключи чат заново.
- `/sync` принимает только запросы с разрешённых `ALLOWED_ORIGINS`, тело до 2 КБ, строгая проверка полей.
- Отправляются только: игровой день, дни тренировок и время, норма выполнена, перемирие, регион и процент гарнизона, число пропусков, программа A/B, число тренировок недели.
