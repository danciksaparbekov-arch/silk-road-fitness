# Шёлковый путь

Игровая карта для домашних тренировок: подходы превращаются в войска, которыми берутся 12 регионов от Иссык-Куля до Лиссабона.

Одностраничное PWA без сборки и зависимостей (кроме шрифтов Google Fonts): `index.html` (интерфейс), `game.js` (чистая логика без DOM), `sw.js` (офлайн-кэш). Прогресс хранится в `localStorage` (ключ `silkroad.v2`, v1 мигрируется автоматически).

## Механики
- **Тренировка**: карточка «Сегодня» с программой A/B ([PROGRAM.md](PROGRAM.md)), каждый подход отмечается ✓ с таймером отдыха. Свободные подходы добавляются в карточке «Поход».
- **Войска**: повторения × сила упражнения = очки; каждые 10 очков группы дают воина (отжимания → копейщики, ноги → конница, тяга → лучники, корпус → щитоносцы), остаток переносится.
- **Битва**: «Атаковать» ведёт всю армию на гарнизон региона, до 6 раундов (залп лучников, затем рукопашная), контры копейщик → конница → лучники, щиты принимают 60% урона.
- **Гарнизоны и золото**: победа даёт добычу, завоёванные регионы платят дань; золото тратится в «Лагере» (стены, лекарь, разведчики, кузнец).
- **Перевалы**: в 4 регионах после падения гарнизона нужно победить стража (тест на максимум).
- **Кузница**: новые варианты упражнений открываются после теста.
- **Провиант**: день с выполненными калориями и белком = 1 провиант; без него очки ×0.5.
- **Усталость/отдых**: 2-я тренировка за день и 3-й день подряд ×0.8, после дня отдыха ×1.1.
- **Ход врага**: пропуск дня → набег; 2 подряд → подкрепление гарнизона; 3 → осада (регион теряется). После пропуска «месть» ×1.3. «Перемирие» (до 7 дней, раз в месяц) и «Перенести на завтра» защищают от штрафов.
- **Честный режим**: слишком быстрые, «пачкой» записанные или нереалистичные подходы помечаются ⚠ и считаются вдвое слабее. Ничего не блокируется.
- **Флот**: +1 кг веса от стартового = +2 всадника и +2 копейщика.
- **Карта недели**: бонусное задание раз в неделю, награда в золоте.
- **Резервная копия**: экспорт и импорт JSON в «Настройках».

## Запуск
Открой `index.html` в браузере.

## Тесты
```
node --test            # tests/game.test.js
node tests/balance.js  # симуляция темпа кампании (Монте-Карло)
```
Размеры гарнизонов (`GARRISON_N` в `game.js`) подобраны симуляцией: идеальный игрок (3 тренировки в неделю) проходит кампанию за 16–22 недели.
