# Шёлковый путь

Игровая карта для домашних тренировок: подходы превращаются в очки, которыми берутся 12 регионов от Иссык-Куля до Лиссабона.

Один файл `index.html`, без сборки и зависимостей (кроме шрифтов Google Fonts). Прогресс хранится в `localStorage` браузера.

## Механики
- **Поход**: очки = повторения × сила упражнения.
- **Перевалы**: в 4 регионах нужно победить стража (тест на максимум).
- **Кузница**: новые варианты упражнений открываются после теста.
- **Провиант**: день с выполненными калориями и белком = 1 провиант; без него очки ×0.5.
- **Усталость/отдых**: 3-й день подряд ×0.8, после дня отдыха ×1.1.
- **Флот**: +100 очков за каждый набранный килограмм.
- **Карта недели**: бонусное задание раз в неделю.

## Запуск
Открой `index.html` в браузере.
